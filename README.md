📌 Project Overview

The Smart Appliances Services website is designed to provide customers with an easy way to explore smart appliances and their related services. The website includes sections for available services, featured appliances, benefits, and contact information.

The project focuses on creating a clean, modern, attractive, and responsive user interface that works smoothly across desktops, tablets, and mobile devices.

✨ Features

- 🏠 Responsive homepage
- 🔌 Smart appliance showcase
- 🛠️ Appliance installation services
- 🔧 Repair and maintenance services
- 📋 Service details section
- ⭐ Customer-focused design
- 📱 Mobile-friendly responsive layout
- 📞 Contact and service enquiry section
- 🎨 Clean and modern UI
- ⚡ Easy navigation

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive elements
- Font Awesome / Icons – Visual elements
- Google Fonts – Typography
