About SmartFix

A complete technical guide.

Purpose & Architecture

The Smart Appliance Service Request System addresses the operational bottlenecks of manual phone-call appliance booking. It provides an asynchronous digital interface allowing customers to report problems, attach photographic evidence of faulty parts, pick convenient repair slots, and receive auto-incrementing tracking IDs (e.g. SR-2026-001).

The architecture is built completely on frontend technologies (HTML5, CSS3, Vanilla JavaScript) utilizing the browser's HTML5 LocalStorage API for persistent data management and the FileReader API for Base64 Data URL conversions.

Enhancements

Limitations

  • Data is restricted to the current browser profile (LocalStorage).
  • No live gateway for payments or credit card processing.
  • Authentication is role-simulated without server session cookies.
  • No real SMS/Email dispatching to technicians.

Future Enhancements for Real-World Deployment

  • Integration of a Node.js/Express REST API with PostgreSQL/MongoDB.
  • Geolocation API & Leaflet maps for live technician tracking.
  • Integration of cloud storage (AWS S3 or Cloudinary) for high-resolution photos.
  • Twilio/SendGrid API for automated SMS and email notifications.
